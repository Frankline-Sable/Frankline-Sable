I enjoy solving the difficult parts of software delivery: reliable integrations, offline-first experiences, data consistency, and systems that remain maintainable as they grow.

My work includes products reaching **100,000+ users**, wearable and biometric data integrations, agricultural advisory platforms, and independently built fintech tools. I also enjoy mentoring developers, writing about engineering, and experimenting with Go and hardware projects.

### 🚀 Selected engineering work

#### [Pesa Radar](https://play.google.com/store/apps/details?id=com.sable.pesa_radar) · Independent project
**Offline-first fintech · Flutter · Hive · Firestore**

An Android personal-finance app that turns transaction SMS into useful financial insights while keeping SMS processing on-device. Built with layered architecture, local-first storage, optional cloud synchronization, and a structured SMS parsing engine. Implemented chunked backup and restore flows with integrity checks.

#### SmartRunning · Professional work
**Wearable integrations · Flutter · FastAPI · GCP**

Contributed to a running and training platform that connects athlete profiles, activity history, training plans, and wearable providers. Built mobile experiences and backend integrations, worked with provider-specific synchronization challenges, and supported data processing and app-store delivery. My work spans Flutter/BLoC, FastAPI services, and cloud data pipelines.

#### FarmBetter · Professional work
**Agri-tech · Flutter · Angular · GraphQL · Firebase**

Worked on an agricultural advisory platform reaching **100,000+ farmers across 10+ countries**. Helped deliver mobile and web experiences designed for practical use in diverse, often connectivity-constrained environments.

#### MyBlueprint / Hoplit · Professional work
**Personal development · Flutter · Firebase**

Contributed to a cross-platform habit, goal, and roadmap application available on iOS and Android, with **30,000+ users**. Worked on mobile features, product improvements, and release delivery.
